## 용어 확인 퀴즈 (5개)

1. **데이터 편향 유형 분류** — 확증 편향·선택 편향·사회적 편향 사례 분류 (9문항)
2. **데이터 전처리 방법 분류** — 정제·통합·축소·변환 중 어떤 방법인지 분류 (10문항)
3. **데이터 시각화 방법 분류** — 시간·분포·관계·공간 시각화 방법 분류 (10문항)
4. **핵심 용어 짝짓기** — 데이터 편향·결측치·이상치·정규화·표준화·대푯값·산포도·상관계수 매칭 게임 (8쌍)
5. **단원 마무리 퀴즈** — 편향, 전처리, 대푯값·산포도, 상관관계·인과관계 등 단원 전체를 아우르는 객관식 10문항

## 실습 단계별 시뮬레이션 (3개) — 오렌지(Orange) 프로그램 위젯 캔버스 재현

교과서에 실린 오렌지 데이터 마이닝 프로그램의 실습 화면(위젯을 연결한 캔버스 + 더블 클릭으로 여는
결과 창)을 그대로 재현했습니다. File·Impute·Box Plot·Formula·Select Rows·Group by·Correlations·
Merge Data·Preprocess·Heat Map 같은 위젯 아이콘이 교과서 화면처럼 번호(➊➋➌)와 함께 연결되어 있고,
위젯을 클릭하면 실제로 더블 클릭했을 때처럼 데이터표·통계·그래프 결과 창이 열립니다.

1. **수면 데이터 전처리 시뮬레이션** (78~82쪽) — File→Data Table/Feature Statistics로 데이터 확인 →
   Impute 위젯에서 결측치 처리 방법 선택(평균 대체) → Box Plot으로 이상치 판별 기준(IQR) 확인 →
   Formula→Select Rows→Feature Statistics로 이상치 처리 전후 비교 → Select Columns→Preprocess로
   표준화 → Merge Data→Scatter Plot/Box Plot으로 시각화까지 7단계
2. **직업별 스트레스 분석 시뮬레이션** (92~98쪽) — Group by로 직업별 데이터 개수 확인 → Select Rows로
   필터링 → Bar Plot으로 평균·중앙값 비교 → Box Plot으로 산포도 비교 → Correlations로 전체/간호사/
   회계사의 상관관계 비교까지 6단계
3. **여행지 데이터 분석 시뮬레이션** (104~113쪽) — 숙소 데이터 속성 파악 → Formula로 1인당 숙박비 계산
   → Box Plot으로 도시별 분포 → Group by/Bar Plot으로 대푯값 비교 → 생활비 데이터 통합(Merge) →
   Scatter Plot/Correlations로 관계 분석 → Preprocess(정규화)/Heat Map으로 종합 분석까지 9단계

교과서에 명시된 실제 수치(사분위수 45/75/IQR 30, 처리 전후 평균 59.61→59.13, 1인당 숙박비 8.8515~
9272.73, 스위스 생활비 지수 평균 115.3 등)는 '📘 교과서 실제 결과' 태그로 표시하고, 정확한 원본
데이터가 없어 만든 예시 값은 '🧪 예시로 체험하기' 태그로 구분해 투명하게 안내합니다. 퀴즈는 정답 시
즉시 해설을 보여주고, 점수·콤보·완료 기록을 브라우저(localStorage)에 저장합니다.

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라, 프레임워크·외부 라이브러리 없음)로 제작한 단일 파일 웹앱입니다.
그래프와 박스 플롯, 산점도는 모두 인라인 SVG로 직접 렌더링합니다. 별도 서버나 빌드 과정 없이 정적
파일만으로 동작하며, 다크/라이트 테마를 지원합니다.
