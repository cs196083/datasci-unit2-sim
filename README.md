## 용어 확인 퀴즈 (5개)

1. **데이터 편향 유형 분류** — 확증 편향·선택 편향·사회적 편향 사례 분류 (9문항)
2. **데이터 전처리 방법 분류** — 정제·통합·축소·변환 중 어떤 방법인지 분류 (10문항)
3. **데이터 시각화 방법 분류** — 시간·분포·관계·공간 시각화 방법 분류 (10문항)
4. **핵심 용어 짝짓기** — 데이터 편향·결측치·이상치·정규화·표준화·대푯값·산포도·상관계수 매칭 게임 (8쌍)
5. **단원 마무리 퀴즈** — 편향, 전처리, 대푯값·산포도, 상관관계·인과관계 등 단원 전체를 아우르는 객관식 10문항

## 실습 단계별 시뮬레이션 (3개)

1. **결측치·이상치 처리 시뮬레이션** — 수면 데이터로 결측치 평균 대체 → 박스 플롯으로 이상치(IQR) 판별
   → 이상치 처리 전후 통곗값 비교 → Z-score 표준화까지 5단계로 체험
2. **대푯값·산포도 비교 시뮬레이션** — 이상치 유무에 따른 평균·중앙값 변화, 최빈값, 분산·표준편차 계산
   과정, A반/B반 박스 플롯 비교를 5단계로 체험
3. **상관관계 탐색 시뮬레이션** — 산점도 유형별 상관계수 비교, 상관계수 계산 과정, 상관관계 vs 인과관계
   (선풍기·아이스크림 사례), 비선형 관계에서 상관계수 해석 시 유의점을 5단계로 체험

각 시뮬레이션은 실제 데이터표·박스 플롯·산점도를 SVG로 직접 그려 보여 주며, 버튼을 눌러 계산 과정을
단계별로 확인할 수 있습니다. 퀴즈는 정답 시 즉시 해설을 보여주고, 점수·콤보·완료 기록을 브라우저
(localStorage)에 저장합니다.

## 기술 스택

순수 HTML/CSS/JavaScript(바닐라, 프레임워크·외부 라이브러리 없음)로 제작한 단일 파일 웹앱입니다.
그래프와 박스 플롯, 산점도는 모두 인라인 SVG로 직접 렌더링합니다. 별도 서버나 빌드 과정 없이 정적
파일만으로 동작하며, 다크/라이트 테마를 지원합니다.
